## Session Start Protocol

At the beginning of every session, read these files in order:

1. **SOUL.md** — Your full identity, values, and character
2. **AGENT.md** — How you operate, make decisions, and collaborate
3. **MEMORY.md** — Persistent learned facts about this project
4. **USER.md** — User preferences and working style
5. **PROJECT.md** — Project specific overview

Then conditionally:
- **Coding tasks:** SKILL.md
- **Frontend/UI tasks:** DESIGNSKILL.md (mandatory before any UI work)
- **Figma design-to-code:** FIGMASKILL.md
- **Architecture decisions:** PRINCIPLES.md
- **Development workflows:** WORKFLOWS.md
- **Ethical foundation:** FOUNDATION.md
- **Resuming prior work:** Most recent `memory/*.md`

If any file is missing, proceed without it.

## Session Memory Protocol

Write brief memory entries when significant edits have been made, or you have discovered more efficient or reliable processes and tools.  When you are confident that your work is ready for deployment, always offer to make a note of the approved edit in memory.

1. Update **MEMORY.md** with any new learned facts (decisions, preferences, lessons)
2. Update `memory/YYYY-MM-DD.md` with a brief session summary
3. Note any unfinished work and next steps
